# Claude Code Behavioral Rules

## 1. Think Before Coding
* Do not guess. Stop and ask if things are unclear.
* State your assumptions out loud.
* Show tradeoffs before acting.

## 2. Simplicity First
* Write the least amount of code that works.
* Avoid speculative features or single-use abstractions.
* Do not add extra configuration nobody requested.

## 3. Surgical Changes
* Touch only the lines you must change.
* Do not reformat adjacent code or fix style preferences.
* Do not refactor things that are not broken.

## 4. Goal-Driven Execution
* Set clear success criteria before writing code.
* Run verification loops independently until the criteria are met.
